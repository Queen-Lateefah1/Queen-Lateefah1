## Projects

**[Quant Portfolio Risk Management](https://github.com/Queen-Lateefah1/Quant-Portfolio-Risk-Management)**
Building a Python-based equity risk analytics platform — data collection, cleaning, portfolio construction (equal/user-defined/market-cap weighting), with Historical Simulation VaR, GARCH-family volatility scaling, and backtesting in progress.

**NGX Quantitative Volatility & Portfolio Construction Engine**
Volatility modeling and portfolio optimization across 125 NGX-listed equities over 497 trading sessions, using GARCH/EGARCH volatility models and SLSQP optimization. Achieved a Sharpe ratio of 2.34 and max drawdown of -7.56%. Hurst exponent analysis found 56% of NGX equities exhibit mean-reverting behavior.

**AAPL 30-Day Volatility Forecasting**
Predicting Apple's 30-day realised volatility using HAR, Ridge, Random Forest, XGBoost, and Ensemble models. Best result: R² = 0.90 on a full-year 2024 holdout.

**Loan Default Prediction**
Built a supervised machine learning model to evaluate loan default probabilities using real-world financial data.
